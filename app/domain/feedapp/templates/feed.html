Setting up the sheet

  1. In the Google Sheet, open Extensions → Apps Script.
  2. Open Project Settings (the gear), and under Script Properties add one called FEED_KEY whose value is the key above. It goes there rather than in the script so that anybody who can read the script cannot read the key.
  3. Back in the editor, replace what is there with this, and save: 
    // Copies the answers to "{{.Form.Title}}" into a tab called Responses.
const FEED = '{{.FeedURL}}';
const TAB = 'Responses';

function pull() {
  const key = PropertiesService.getScriptProperties().getProperty('FEED_KEY');
  const res = UrlFetchApp.fetch(FEED, {
    headers: { Authorization: 'Bearer ' + key },
    muteHttpExceptions: true,
  });
  if (res.getResponseCode() !== 200) {
    throw new Error('The feed answered ' + res.getResponseCode() + ': ' + res.getContentText());
  }
  const feed = JSON.parse(res.getContentText());

  const head = ['Reference', 'Received', 'Last changed', 'Times changed', 'Email']
    .concat(feed.fields.map(f => f.label));
  const rows = feed.responses.map(r => [
    r.id, new Date(r.created_at), new Date(r.updated_at), r.changes, r.email,
  ].concat(feed.fields.map(f => {
    const v = r.answers[f.name];
    return v == null ? '' : Array.isArray(v) ? v.join(', ') : v;
  })));

  const book = SpreadsheetApp.getActive();
  const sheet = book.getSheetByName(TAB) || book.insertSheet(TAB);
  sheet.clearContents();
  sheet.getRange(1, 1, 1, head.length).setValues([head]).setFontWeight('bold');
  if (rows.length) sheet.getRange(2, 1, rows.length, head.length).setValues(rows);
  sheet.setFrozenRows(1);
}
  4. Choose pull beside the Run button and press Run. Google will ask you to allow it to reach this site and change the sheet; allow it. A Responses tab appears.
  5. Open Triggers (the clock), Add Trigger, choose pull, Time-driven, every 5 or 10 minutes.

The tab is rewritten each time, one row per answer, oldest first, so a person keeps the row they were on. Hidden submissions are left out, as they are from the download. Point your own sheets at this tab — by reference or by email, with XLOOKUP or VLOOKUP — rather than typing into it, because whatever is typed into it is replaced at the next pull.
