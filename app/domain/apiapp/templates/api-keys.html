API keys

Your account

An API key lets a program build forms and read their answers for you — Claude, for instance, when you ask it to make a form. When you connect Claude on claude.ai, it is given a key of its own, which is listed here and can be revoked here like any other. A key acts as {{.Email}}: it can reach exactly the forms you can, and do exactly what you can do with them, and nothing else. It cannot make another key.

Using it

On claude.ai, you do not need a key at all: add a custom connector with the address {{.BaseURL}}/api/mcp, and Claude will send you here to agree.

Anywhere else, send the key with every request, as a header:

curl -H "Authorization: Bearer $DROPIN_KEY" {{.BaseURL}}/api/v1/forms

To have Claude build a form, give it the key and the API reference (docs/api.md in the service's repository), and describe the form you want. New forms are made unpublished: look at one in the builder before you put it on the web.
